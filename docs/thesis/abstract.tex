\begin{abstract}
Event-centric knowledge graphs (EKGs) have emerged as powerful tools for representing complex temporal and contextual relationships between events and entities. However, current evaluation methods for EKGs are fragmented, focusing on isolated features such as precision and recall while overlooking critical dimensions including temporal density, structural coherence, and semantic completeness. This research addresses this gap by developing a comprehensive evaluation framework specifically designed for EKGs. The framework integrates established metrics such as temporal consistency and schema conformance with metrics for entity richness, external mapping coverage, type consistency, and predicate usage patterns, applying them together to EKGs for the first time. We implement the framework as an open-source tool, ekg-eval-cli, and validate it against synthetic event graphs with known ground truth. Experimental results demonstrate that the framework successfully captures multidimensional EKG quality across nine evaluation dimensions with 32 metrics, revealing quality differences that single-dimension approaches miss. The primary contribution is a standardized, holistic evaluation approach that enables systematic comparison of EKG quality and guides future improvements in event-centric knowledge representation. This work advances the field by providing researchers and practitioners with a practical, automated methodology for assessing EKG quality across multiple dimensions simultaneously.
\end{abstract}
