\begin{abstract}
Event-centric knowledge graphs (EKGs) have emerged as powerful tools for representing complex temporal, causal, and contextual relationships between events and entities. However, current evaluation methods for EKGs are fragmented, focusing on isolated features such as precision and recall while overlooking critical dimensions including causal reasoning, contextual completeness, and event granularity. This research addresses this gap by developing a comprehensive evaluation framework specifically designed for EKGs. The framework integrates established metrics such as temporal consistency and schema conformance while introducing novel metrics for reasoning capabilities, entity richness, and external mapping coverage. We implement the framework as an open-source tool, ekg-eval-cli, and validate it against benchmark datasets including EventKG, synthetic event graphs, and ASER. Experimental results demonstrate that the framework successfully captures multidimensional EKG quality across ten evaluation dimensions, revealing insights that traditional methods miss. The primary contribution is a standardized, holistic evaluation approach that enables systematic comparison of EKG models and guides future improvements in event-centric knowledge representation. This work advances the field by providing researchers and practitioners with a robust methodology for assessing EKG effectiveness across diverse application domains.
\end{abstract}
