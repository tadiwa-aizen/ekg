\section*{Abstract}
Event-centric knowledge graphs (EKGs) represent events together with temporal, contextual, and entity-related information. Existing evaluations often examine only one aspect of quality, such as extraction accuracy, temporal coverage, graph structure, or performance on a downstream task. This makes it difficult to compare EKGs or identify their strengths and weaknesses across several dimensions.

This thesis addresses this problem by designing, formalising, implementing, and evaluating a multidimensional framework for the intrinsic quality of RDF-based EKGs. The framework uses 28 distinct metric calculations across nine selected dimensions: graph connectivity and structure, redundancy and duplication, temporal consistency, minimal event-profile alignment, completeness, closed-profile type alignment, entity richness, external mapping coverage, and predicate usage. The software reports these calculations through 32 named fields. Four fields repeat a calculation so that each reporting module can include the relevant result. The framework combines measures adapted from EKG and general knowledge-graph literature with measures formalised for this study. It is implemented as a command-line tool that uses SPARQL and graph analysis.

The evaluation uses three controlled datasets designed to represent high-, mixed-, and low-quality conditions, four general RDF/KG quality tools (RDFUnit, KGHeartBeat, Luzzu, and SANSA), and two independently produced real-world sources (OEKG and ChronoGrapher). On the controlled datasets, the framework clearly separates the three quality profiles. Temporal coverage decreases from \DOneTemporalCoveragePct\% to \DTwoTemporalCoveragePct\% and \DThreeTemporalCoveragePct\%, while minimal profile completeness decreases from \DOneCompletenessPct\% to \DTwoCompletenessPct\% and \DThreeCompletenessPct\%. These results show which aspects of quality changed instead of reducing each dataset to a single score.

Compared with these four tools, the proposed framework reports a wider range of event-specific checks, although their measures cannot be compared on one numerical scale. The complete cleaned OEKG event layer, containing \OEKGEvents\ direct events and \OEKGTriples\ triples, shows that the framework can run on a large published EKG. In the ChronoGrapher artefacts, it finds that direct events have no labels and that type alignment cannot be calculated because no relevant domain or range rules apply.

Together, the results show that the framework helps researchers identify strengths, weaknesses, and missing evidence in an RDF-based EKG. It provides a clearer basis for dataset auditing and targeted improvement than a single score or narrow metric subset.
