\section{Introduction to Results}

This chapter presents the results of applying the evaluation framework described in Chapter 3 to three synthetic event-centric knowledge graphs with known ground truth. The results are organised around the three research questions established in Chapter 1:

\begin{itemize}
    \item \textbf{RQ1:} What dimensions of quality are relevant for event-centric knowledge graphs, and how can they be systematically measured?
    \item \textbf{RQ2:} Can a comprehensive evaluation framework reveal quality differences across EKG systems that are missed by traditional, narrow evaluation approaches?
    \item \textbf{RQ3:} How do EKGs of varying quality perform across multiple dimensions, and what trade-offs exist between dimensions?
\end{itemize}

To answer RQ1 (\textit{What dimensions of quality are relevant for EKGs, and how can they be systematically measured?}), we applied the framework to all three synthetic datasets and report the full results for each dimension. Dataset 1 (synthetic-event-kg, 100 events) serves as a clean baseline; Dataset 2 (synthetic-event-kg-2, 150 events) includes intentional quality degradation in selected dimensions; Dataset 3 (synthetic-event-kg-3, 120 events) is designed to score poorly across all dimensions while remaining a structurally valid EKG.

\subsection{What Single-Dimension Evaluation Would Miss}

To illustrate the value of multidimensional assessment, consider four hypothetical single-dimension evaluations:

\textbf{Temporal-only evaluation:} Datasets 1 and 2 score identically (100\% on all temporal rates). Conclusion: equivalent quality. Missed: the 196\% increase in fuzzy duplicates and 30\% drop in DBpedia coverage between them.

\textbf{Completeness-only evaluation:} Datasets 1 and 2 both score 100\% population completeness. Conclusion: both are equally complete. Missed: Dataset 2 has 66\% richer events but 54\% lower label uniqueness.

\textbf{Size-only evaluation:} Dataset 2 has the most events (150), Dataset 3 has 120, Dataset 1 has 100. Conclusion: Dataset 2 is best. Missed: Dataset 3 is worse than Dataset 1 on every quality dimension despite having 20\% more events.

\textbf{Schema conformance only:} All three datasets score 0\%. Conclusion: all equally bad. Missed: the enormous differences in temporal coverage (100\% vs 57.50\%), external mapping (100\% vs 15.83\%), and entity richness (9.24 vs 3.62 properties per event).

Only the multidimensional framework captures the full quality profile, revealing that Dataset 2 represents a different set of trade-offs relative to Dataset 1, while Dataset 3 is uniformly worse across all dimensions.

\section{Cross-Dimensional Patterns and Trade-offs (RQ3)}

To answer RQ3 (\textit{How do EKGs of varying quality perform across multiple dimensions, and what trade-offs exist?}), we analyse patterns across dimensions using all three datasets.

\subsection{Observed Trade-offs}

The three-dataset comparison reveals trade-offs between Datasets 1 and 2, and uniform degradation in Dataset 3:

\textbf{Richness vs Redundancy (DS1 vs DS2):} Dataset 2 events have 66\% more properties per event but 54\% lower label uniqueness and 196\% more fuzzy duplicates. Adding more properties to events appears to correlate with increased duplication. Whether this reflects a genuine trade-off or an artefact of the data generation process cannot be determined from intrinsic evaluation alone.

\textbf{Temporal Density vs External Mapping (DS1 vs DS2):} Dataset 2 has better temporal distribution (3 gaps vs 8) but worse external linking (70--76\% vs 100\%). More events are distributed across time, but fewer are linked to external knowledge bases.

\textbf{Uniform Degradation (DS3):} Dataset 3 does not exhibit trade-offs---it is worse on every dimension. This pattern is qualitatively different from the DS1-vs-DS2 comparison and demonstrates that the framework can distinguish between datasets with quality trade-offs (DS2) and datasets with uniformly poor quality (DS3). This distinction is important for practitioners: a dataset with trade-offs may be suitable for specific tasks, while a uniformly poor dataset is unlikely to be suitable for any task.

\subsection{Consistent Patterns}

Several patterns are consistent across all three datasets:

\begin{itemize}
    \item \textbf{Location absence:} No dataset includes \texttt{sem:hasPlace}, making schema conformance uniformly 0\%. This is a data generation limitation, not a framework limitation.
    \item \textbf{Schema coverage:} All three datasets use only 1 of 5 declared event classes (20\% schema coverage), indicating that the OEKG schema overlay declares subclasses that none of the synthetic datasets instantiate.
    \item \textbf{Type consistency:} All three score 100\% because the schema-declared properties are not used in the data. This metric would become informative on datasets with richer schema usage.
\end{itemize}

\section{Summary of Key Findings}

The evaluation produced four key findings that directly address the research questions:

\textbf{Finding 1 (RQ1):} All nine dimensions are measurable through automated analysis. The framework computed 32 metrics across all three datasets using SPARQL queries and NetworkX graph analysis, with no manual annotation required. One metric (type consistency) was computable but uninformative due to the absence of actively used schema-constrained properties, highlighting that metric informativeness depends on data characteristics.

\textbf{Finding 2 (RQ2):} The comprehensive framework reveals quality differences invisible to single-dimension evaluation. Datasets 1 and 2 score identically on temporal coverage, label coverage, schema conformance, and type consistency, yet differ substantially on redundancy, external mapping, and entity richness. Dataset 3 scores worse than both on every informative dimension. Any single-dimension evaluation would produce an incomplete and potentially misleading quality assessment---for example, all three datasets score 0\% on schema conformance, yet they differ enormously on every other dimension.

\textbf{Finding 3 (RQ3):} The three-dataset comparison reveals two distinct quality patterns. Between Datasets 1 and 2, cross-dimensional trade-offs exist: Dataset 2 is richer but more redundant, with better temporal density but worse external mapping. Dataset 3 exhibits uniform degradation with no compensating strengths. The framework's ability to distinguish between trade-off patterns and uniform degradation provides actionable guidance: a dataset with trade-offs may suit specific tasks, while a uniformly poor dataset requires improvement across all dimensions.

\textbf{Finding 4 (Validation):} Ground truth comparison identified eight implementation bugs that produced plausible but incorrect results. This finding underscores the importance of systematic validation for EKG evaluation tools and demonstrates that the framework's modular design facilitated targeted bug identification and correction.

These findings are discussed in depth in Chapter 5, where we examine their implications for EKG evaluation practice, compare with prior work, and identify limitations and future directions.
