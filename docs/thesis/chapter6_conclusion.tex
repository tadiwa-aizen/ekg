\chapter{Conclusions and Future Work}
\enlargethispage{\baselineskip}

This thesis addressed fragmented evaluation of RDF-based event-centric knowledge graphs by designing, formalising, implementing, and evaluating a multidimensional intrinsic framework. It contains 28 distinct calculations across nine selected dimensions. The implementation exposes 32 named result fields because four are aliases used by more than one reporting module. The methodology and appendix record the formulae, denominators, unavailable-value rules, implementation paths, and provenance. Aliases are interpreted once and are not treated as independent evidence. The command-line tool uses SPARQL, deterministic sampling, file streaming, NetworkX, and a disk-backed path for large graphs.

Three conclusions follow within the scope of this study. First, the framework responds to controlled high-, mixed-, and low-quality profiles and exposes trade-offs missed by narrow metric subsets. Second, RDFUnit, KGHeartBeat, Luzzu, and SANSA provide useful general checks, but their measures do not form one event-specific quality profile. Third, the framework runs on independently produced RDF event data, including the complete cleaned OEKG event layer and three public ChronoGrapher artefacts. These runs also show why profile compatibility and \texttt{N/A} reporting are necessary.

The contribution is therefore broader intrinsic coverage and more detailed diagnosis within the stated RDF-EKG scope. It is not a universal quality score or proof that one tool is best for every purpose. The results do not establish factual truth, causal correctness, or downstream task suitability. External validity remains limited to the evaluated SEM-style artefacts, and the controlled datasets are not an independent benchmark.

Future work should construct an independently designed or blinded EKG quality benchmark and evaluate real graphs that use other vocabularies. Factual and causal validation will require suitable reference evidence and annotation protocols. Task-based experiments should test whether intrinsic profiles predict performance in retrieval, question answering, timeline construction, or other declared uses. Scalability work should reduce repeated large-file scans and add disk-backed clustering approximations with stated error bounds. The external coverage rubric should be coded independently, and new metrics or profiles should extend the regression suite.
