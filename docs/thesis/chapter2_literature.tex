\chapter{Literature Review}


This chapter reviews event-centric knowledge graphs and the approaches used to evaluate them. It establishes the concepts needed by the thesis, examines published EKG construction approaches, compares existing evaluation frameworks and methods, and identifies the central gap addressed by this research.

The chapter has four parts. Section~2.1 explains how event representation and temporal modelling create quality questions beyond those usually considered for entity-centred graphs. Section~2.2 reviews published EKGs and compares intrinsic, extrinsic, and human-judgement approaches. Section~2.3 examines recurring evaluation designs and states the limitation of each design when it is used alone. Section~2.4 then states the research gap.

\section{Conceptual and theoretical foundations}

Entity-centred assessment can check whether triples and schema statements are valid, but an EKG also raises questions about whether events have suitable temporal anchors, participants, places, and relationships to other events. This section first contrasts entity-centred and event-centred representation, then explains the temporal and quality concepts needed to evaluate those additional properties.

\subsection{Event-centric knowledge graphs}

Event-centric knowledge graphs differ from entity-centred graphs by representing events as first-class nodes and organising related information around them \citep{sem2011}. For example, ``Person A works at Company B'' records an entity relationship but does not identify the event through which that relationship began. An event-centred representation can add the event, its date, place, participants, and links to other events. Listings~\ref{lst:entity-centred-example} and~\ref{lst:event-centred-example} show this contrast in both text and RDF. The distinction matters for evaluation because an EKG must be assessed not only for valid entity relationships, but also for the quality of its event context.

The Simple Event Model (SEM) is a foundational model for event representation. It supports actors, places, and time without requiring every domain to use the same detailed event structure \citep{sem2011}. This flexibility also means that SEM does not define one universal level of completeness. For example, an event with a date may be sufficient for a simple timeline but may still lack the participants and relationships needed for causal analysis.

The evaluation implication is that completeness must be stated relative to a declared event profile or use case. This thesis therefore reports separate measures for properties such as labels, time, place, description, and external links rather than claiming that one absolute completeness score applies to every EKG.

\subsection{Temporal modelling and constraints}

Temporal modelling adds significant complexity to event representation and evaluation. Events can be anchored explicitly through timestamps or only inferentially through temporal relations; temporal constraints can be underspecified; and logically equivalent temporal structures may be expressed through different edge sets. TimeML is a markup specification for events, temporal expressions, and ordering relations; it does not perform reasoning itself, but it shows why evaluation needs to account for structured temporal constraints rather than only checking whether a timestamp is present \citep{timeml2003}.

This temporal complexity has direct implications for evaluation: two EKGs might represent the same temporal reality through different but logically consistent structures, yet traditional precision-recall metrics may penalise such differences if they compare only explicit edges. Temporal closure means adding relations that follow logically from those already stated (for example, if A is before B and B is before C, then A is before C). It can therefore make temporal-relation evaluation fairer when the target is event ordering \citep{tempeval2011}.

For this thesis, the main lesson is that temporal quality cannot be represented by a single check. Timestamp presence, literal validity, temporal granularity, and ordering consistency provide different evidence. The implemented framework measures these properties separately; it does not claim to perform full temporal-closure comparison between logically equivalent graphs.

The preceding discussion establishes why event and temporal representation introduce distinct evaluation requirements. The review now turns to the broader KG quality literature to identify how such requirements can be organised into dimensions.

\subsection{Evaluation dimensions for knowledge graphs}

The broader knowledge graph quality literature treats ``quality'' as multidimensional. Surveys identify dimensions including accuracy, completeness, consistency, timeliness, and provenance, and distinguish assessment from the later tasks of detecting, correcting, and completing faulty data \citep{kgquality2021,kgquality2024}. General linked-data frameworks have also implemented multidimensional assessment. Luzzu, for example, provides an extensible metric architecture and scalable assessment process \citep{luzzu2016}. This work establishes that quality can be organised and measured across several dimensions, but it does not determine which event-specific properties an RDF EKG evaluation should include.

For EKGs specifically, quality assessment should address not only correctness of extracted triples but also whether the graph represents event structure (what happened), event grounding (who, where, and when), and event relations. The literature therefore supplies a multidimensional starting point, while the event representation literature identifies additional properties that need to be made explicit. The next section examines how published EKGs are constructed and what their authors evaluated.

\section{Prior work on event-centric knowledge graphs}

This section reviews how EKGs are constructed and evaluated, then identifies which existing tools and frameworks provide useful but partial foundations for this thesis.

\subsection{Construction of event-centric knowledge graphs}

Published EKGs are built in three broad ways: by integrating existing structured sources, by extracting event knowledge from text, or by modelling events for a specific domain and application. These construction choices matter because they create different quality risks and therefore motivate different evaluation evidence.

EventKG represents the first approach. It combines event information from sources including Wikipedia, Wikidata, and DBpedia into a large-scale multilingual event knowledge base \citep{eventkg2018}. Its construction process aligns event descriptions, retains source provenance, and adds temporal and spatial context. Figure~\ref{fig:eventkg-construction-pattern} summarises this integration-focused design. For evaluation, this makes source coverage, event identification, provenance, time, and location central concerns.

ASER (Activities, States, Events, and their Relations) represents the second approach. It extracts eventuality knowledge from large text corpora using syntactic patterns and a typed relation inventory influenced by discourse relation schemes \citep{aser2019}. Unlike EventKG, its main quality questions concern whether text-derived eventualities and relations are valid and useful, so its evaluation emphasises sampled extraction accuracy, scale, coverage, and commonsense reasoning tasks. ASER is relevant here because it shows why one evaluation design cannot be assumed to fit every event graph.

The Open Event Knowledge Graph (OEKG) is another integration case. It assembles seven datasets for tasks including question answering, entity recommendation, and named entity recognition through named graphs and links to EventKG \citep{oekg2023}. This design makes multilingual access, named-graph provenance, and cross-dataset linking relevant quality concerns. It also explains why OEKG is used later as a public RDF execution case: its representation differs from the controlled SEM-style datasets while retaining identifiable event data.

The third approach is domain-specific modelling. NewsReader-style EKGs build temporal event networks from news corpora for narrative analysis \citep{newsreader2016}. AugGKG supports spatio-temporal queries for location-based event analysis \citep{auggkg2023}. Public-administration and auditing EKGs represent changes in organisational records, public-service interactions, or process-mining data \citep{paekg2024,auditingekg2024}. These examples matter because their intended tasks place different weight on temporal detail, location, provenance, and process relations.

Together, these cases show that EKG construction affects what should be evaluated. Extraction-based graphs need evidence about extraction validity; integrated graphs need evidence about coverage, provenance, alignment, and duplication; and domain-specific graphs need evidence tied to their intended use. No single published construction study supplies all of these forms of intrinsic evidence. Having established this variation, the next subsection reviews the evaluation approaches and frameworks that can be applied to knowledge graphs.

\subsection{Evaluation of knowledge graphs}

Knowledge graph evaluation can be divided into three broad approaches. Intrinsic evaluation inspects properties of the graph. Extrinsic evaluation tests the graph in a task. Sampled human evaluation asks people to judge selected statements or extracted relations. The three approaches answer different questions and produce different evidence.

\subsubsection{Intrinsic evaluation approaches}

Intrinsic evaluation assesses a graph without running a downstream task. Constraint and schema validation provide a basic example. RDF Schema defines terms such as classes, subclass relationships, domains, and ranges. Test-driven linked-data assessment turns such expectations into reusable checks, often expressed as SPARQL queries \citep{rdfs2014,testdriven2014}.

Luzzu provides a broader intrinsic example. A user selects metric implementations, Luzzu processes the RDF data, and the framework reports the resulting quality values and metadata \citep{luzzu2016}. Its plugin design makes it useful for repeatable Linked Data assessment. However, its available metrics are general rather than event-specific. They do not jointly check the temporal information, minimum event profile, and event-focused structure required in this thesis.

\subsubsection{Extrinsic evaluation approaches}

Extrinsic evaluation measures how a graph performs in a downstream task. KGrEaT compares KGs under fixed classification, clustering, or recommendation experiments after mapping the required entities between graphs \citep{kgreat2023}. For example, two graphs can be used as alternative inputs to the same classification task and compared through the resulting task performance. This shows whether one graph is more useful for that experiment, but it does not explain every intrinsic reason for the difference. KGrEaT also shows that labels and descriptions can affect downstream use, so an intrinsic completeness value should not be treated as a direct prediction of task performance.

For EKGs, task-based evaluation often focuses on question answering. Event-QA uses complex SPARQL queries and multilingual verbalisations to test whether EventKG can answer questions involving event-entity relations and temporal constraints \citep{eventqa2020}. ChronoGrapher uses a human study to compare answers produced with event-centric and generic entity-centric graph context, and reports stronger answer grounding with event-centric context \citep{chronographer2023}. These studies demonstrate task utility. They do not provide a multidimensional intrinsic profile of the RDF graph itself, which is the problem addressed in this thesis.

\subsubsection{Scalable human-in-the-loop auditing}

Human evaluation can use either a preconstructed gold standard or judgements collected for a sample. A gold standard is itself created through annotation, but it is prepared as reference data before system outputs are scored. Sampled auditing instead selects statements from the graph and asks annotators to judge whether they are correct. The result estimates accuracy for the sampled population under the stated sampling design; it is not a complete reference graph.

For large or changing KGs, \citet{efficienteval2019} describe stratified and incremental sampling procedures that reduce annotation effort while retaining a stated statistical basis for the estimate. NewsReader and ASER provide EKG examples in which people judge sampled event triples or extracted eventualities \citep{newsreader2016,aser2019}. This evidence can assess factual or extraction accuracy, but it does not replace structural, temporal, completeness, or mapping checks. The framework developed in this thesis does not implement human factual-accuracy sampling; it focuses on repeatable intrinsic measures that can be computed from the RDF data.

\citet{tieval2023} illustrate why a shared evaluation procedure matters. The framework gives temporal information extraction systems common corpus access and closure-aware evaluation. This reduces differences caused by incompatible annotation formats and evaluation scripts. Its scope is nevertheless temporal information extraction, not the broader intrinsic quality of a published RDF event graph.

Recent work also uses language models during validation. KGValidator applies LLM-assisted judgement to KG completion outputs in order to reduce manual labelling \citep{kgvalidator2024}. This may help where a triple cannot be checked through a schema rule alone, but the judgement depends on the model and its evidence. It therefore complements rather than replaces declared RDF checks or human validation.

The comparison shows the relationship to the research problem. Existing approaches provide useful evidence about general Linked Data quality, temporal extraction, downstream tasks, or sampled correctness. In the work reviewed here, they do not combine these concerns into one reusable intrinsic profile for RDF-based EKGs.

\section{Methodological patterns in the literature}

The studies reviewed above use recurring evaluation designs even when their datasets, graph models, and research questions differ. This section explains what each design measures, what it contributes, and what remains hidden when it is used alone.

\subsection{Common evaluation designs}

Across the EKG literature, evaluation methods cluster into several recurring patterns. Each pattern is useful for a stated purpose, but none should be read as a complete account of EKG quality.

\subsubsection{Triple-level precision, recall, and F1}

Triple-level precision, recall, and F1 are commonly used when a system classifies candidate event relations or extracts event triples. The predicted relation classes are compared with human-annotated reference labels. \citet{eventevolution2009}, for example, evaluate extracted event-evolution relations against manually annotated relations. Sampled extraction-accuracy procedures also appear in NewsReader and ASER \citep{newsreader2016,aser2019}. These measures give clear evidence about the selected extraction task. They do not show whether the resulting graph is complete, well connected, richly described, or externally linked, and equivalent high-level event structures may use different valid edge sets.

\subsubsection{Coverage and attribute-level correctness}

Coverage and completeness measures are common for integrated encyclopedic EKGs. \citet{eventkg2018} report event coverage and compare the presence of time and location information across sources. They also use annotations over sampled events to evaluate event identification, time fusion, and location fusion. This gives direct evidence about important event attributes. It does not by itself describe graph structure, duplicate risk, description richness, causal correctness, or multi-hop task performance. Causal and multi-hop evaluation require additional reference data or task experiments and remain outside the implemented scope of this thesis.

\subsubsection{Crowdsourced and expert judgement}

When a complete gold standard is unavailable, researchers can collect post-hoc judgements for a sample. NewsReader uses human judgement over randomly sampled event triples \citep{newsreader2016}. ASER samples extracted eventualities and asks annotators whether they preserve the meaning of the source sentence; it also compares its knowledge with ConceptNet and tests commonsense-reasoning tasks \citep{aser2019}. These procedures provide useful factual or extraction evidence for the sampled population. They do not produce a complete multidimensional profile, and the result depends on the sampling design and annotation protocol.

\subsubsection{Temporal-specific evaluation}

Some authors evaluate temporal information in order to test whether a system preserves event order and implied temporal relations. \citet{tempeval2011} use temporal closure so that a predicted relation can receive credit when it is logically implied rather than explicitly stated. QA TempEval instead evaluates temporal understanding through question answering \citep{qatempeval2015}. Closure-aware scoring is useful for temporal relation extraction, while question answering tests task usefulness. Neither approach alone reports the broader intrinsic condition of an RDF EKG.

\subsubsection{Causality evaluation}

Causality evaluation usually treats causal-relation identification as a classification task over annotated text. Causal-TimeBank and the Event StoryLine Corpus provide reference annotations for temporal and causal relations \citep{causaltimebank2014,storyline2017}. MECI extends causal-relation identification across languages \citep{meci2022}. These resources can evaluate whether a system extracts selected causal relations. They do not establish that a complete EKG supports reliable causal inference. The present framework does not claim to solve that problem; causal correctness remains a separate validation task.

\subsubsection{Graph-structure-level evaluation}

Graph-level evaluation asks whether the structure of an event graph is coherent or similar to a reference graph. \citet{glavas2014} compare automatically and manually constructed event graphs through tensor-product-based structural measures. Version~1 of the STAGE preprint evaluates structural coverage and faithfulness for event summarisation \citep{stage2026}. These approaches move beyond independent edge scoring, but both require a task-specific reference or output. They do not provide a reusable intrinsic evaluator for an arbitrary published RDF EKG.

Taken together, the recurring designs measure different objects: extracted relations, represented attributes, sampled statements, temporal reasoning, causal extraction, or graph structure. Their values cannot be combined without preserving those differences. A high extraction F1 does not imply high event-attribute coverage, just as high temporal coverage does not imply that the dates are factually correct.

\subsection{Shared methodological limitations}

The limitations described above have one common effect: results from different EKG studies are difficult to compare. They may concern different objects, use different reference evidence, and divide by different populations. For example, temporal-closure F1 compares predicted temporal relations with reference relations, while event-attribute coverage divides events with a property by an event population. Averaging these values would hide what each one means. A graph can also have high temporal coverage but poor location coverage, duplicate labels, or weak connectivity. A temporal result alone would not reveal those problems.

The lack of full-graph gold standards creates a second boundary. Sampled human judgement can estimate factual or extraction accuracy, but it cannot by itself test every structural and contextual property of a large EKG. Conversely, computable intrinsic metrics can describe the graph but cannot prove that its statements are true. This thesis addresses the computable intrinsic side of the problem and reports factual and causal correctness as outside scope.

Other concerns remain important but are not the main target of this study. Event granularity depends on the intended queries and domain expectations \citep{sem2011,eventkg2018}. Multilingual and cross-domain studies commonly report task-specific evidence rather than one shared quality profile \citep{oekg2023,eventqa2020,meci2022}. Evolving KGs also need repeated or incremental assessment, while many published evaluations remain snapshots \citep{kgevolution2023,efficienteval2019}. These concerns support future extensions, but they are not treated as completed dimensions in the present framework.

The priority for this thesis is therefore narrower and explicit: organise the computable intrinsic evidence that can be obtained from RDF event graphs, define its populations and denominators, and test whether the combined profile reveals information that selected narrow views miss.

\section{The research gap addressed by this thesis}

The literature points to one central gap: within the work reviewed here, there was no reusable evaluation process that reported a broad intrinsic RDF-EKG quality profile with clear metric definitions, populations, denominators, and unavailable-value rules. Existing work provides important parts of such an evaluation, but those parts remain spread across general Linked Data frameworks, temporal and extraction benchmarks, EKG resource studies, task evaluations, and sampled human audits.

This gap has three connected parts. First, the evidence is fragmented. Extraction precision, temporal coverage, QA performance, sampled correctness, and graph structure answer different questions and cannot be read as one measure. Second, several recurring event-specific concerns do not have a shared RDF-level operationalisation across the reviewed tools. These include the joint treatment of event structure, temporal representation, minimum event attributes, description richness, duplication, external mapping, and predicate use. Third, the literature gives limited direct evidence about what is learned when these intrinsic concerns are evaluated together rather than one at a time.

The thesis responds to these parts in sequence. RQ1 identifies and formalises a set of intrinsic dimensions and metrics. The command-line implementation makes those definitions executable and repeatable, but the software is the means of testing the framework rather than the contribution by itself. RQ2 compares the combined profile with selected narrow views and general RDF/KG tools. RQ3 applies the profile to controlled datasets and independently produced public RDF event graphs. Factual truth, causal correctness, multilingual quality, and downstream task performance remain separate forms of evidence and are not claimed as solved by this framework.
